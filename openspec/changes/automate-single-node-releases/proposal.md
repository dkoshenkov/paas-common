# Proposal

## Why

PAAS-006 требует автоматического расчёта версий трёх репозиториев. Common уже выпущен как SDK `1.1.0`; ctl и daemon пока не имеют удалённых тегов. Мультинод отложен до v2, поэтому релизы однодового продукта продолжаются в v1.

## What Changes

- Предложить автоматический расчёт версии для каждого репозитория с minor по умолчанию и patch для обычного `fix`; breaking в рамках однодовой ветки предлагает minor.
- Продолжать `paas-common` с существующей версии `1.1.0`, не выпускать автоматически `2.0.0`; для ctl и daemon начать с согласованной версии `1.0.0`.
- Локально формировать manifest и CHANGELOG из подтверждённого диапазона Git. Механизм публикации и права GitHub согласуются отдельно.

## Capabilities

### New Capabilities

- `single-node-release-versioning`: политика и автоматизация релизов однодовой ветки в трёх репозиториях.

### Modified Capabilities

Нет.

## Impact

Затрагиваются release workflows, конфигурация и проверки `paas-common`, `paas-ctl`, `paas-daemon`, GitHub Actions и Release Please. Код продукта и контракты API не меняются. Локальный расчёт согласован. Подключение GitHub, публикация и переход на v2 требуют отдельных решений.
