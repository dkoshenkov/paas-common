# pgx-read-snapshots Specification

## Purpose

Управлять read-only транзакцией PostgreSQL для нескольких согласованных чтений через нативный пул pgx.

## Requirements

### Requirement: Чтения выполняются в защищённом снимке

`ReadSnapshot` SHALL передавать callback нативную `pgx.Tx` в `READ ONLY REPEATABLE READ` и возвращать значение только после успешного завершения callback и освобождения транзакции.

#### Scenario: Конкурентное обновление
- **WHEN** другая сессия изменяет строку между двумя чтениями callback
- **THEN** оба чтения видят одну версию строки, а вставка через транзакцию отклоняется PostgreSQL

#### Scenario: Завершение с ошибкой
- **WHEN** callback возвращает ошибку или не удаётся начать транзакцию
- **THEN** вызывающий получает ошибку и нулевое значение результата

### Requirement: Освобождение соединения ограничено по времени

`ReadSnapshot` SHALL пытаться откатить начатую транзакцию даже после отмены исходного контекста и при panic. Откат MUST иметь собственный положительный таймаут. Ошибка callback сохраняет приоритет перед ошибкой отката. При ошибке только отката значение результата SHALL быть нулевым.

#### Scenario: Отмена или panic внутри callback
- **WHEN** отменён контекст запроса или callback вызвал panic
- **THEN** соединение освобождается, а при panic вызывающий видит исходный panic

#### Scenario: Потеря сессии перед завершением
- **WHEN** успешный callback возвращает результат, но rollback завершился ошибкой
- **THEN** библиотека возвращает ошибку, а daemon выдаёт безопасный отказ зависимости
