## Воспроизведение

Подготовить отдельную VM с k3s по [приёмке установки ноды](k3s-node-check-2026-11-07.md).
Требуются готовые CoreDNS и provisioner local-path, импортированный образ daemon,
проверенные SSH-ключи и Python 3. Сборка образа описана в `paas-daemon/README.md`,
установка — в `paas-ctl/README.md`. Скрипт приёмки из `paas-ctl/scripts`:

```sh
sudo sh scripts/test-postgres-node.sh --disposable-vm /path/to/paas-ctl /path/to/admin-key /path/to/paas-key "$image" admin 22
```

Приёмка выполняет действия внутри выделенной VM через SSH на 127.0.0.1.
На уже проверяемой установке применяется `--existing-fixture`.
Дополнительный `--lose-runtime-secret` проверяет реальную потерю Secret в конце
прогона; после него тестовую VM следует удалить. В этих прогонах kubelet получал
системные OCI-образы из сверенного официального архива k3s, поскольку Docker
Hub периодически был недоступен. На действующем кластере этот destructive-тест
не требуется.
