# Локальное переименование в paas-common

Дата: 2026-10-18. Согласован только этап переименования, не реализация платформы.

## Изменения

- Каталог и Go module path переименованы в paas-common; Git-история сохранена.
- OpenSpec и три backlog-файла перенесены внутрь репозитория.
- Команды OpenSpec запускаются из корня paas-common; AGENTS.md в workspace
  направляет к инструкциям репозитория.
- По отдельному разрешению пользователя GitHub-репозиторий переименован в
  dkoshenkov/paas-common через веб-настройки GitHub; результат проверен по странице
  репозитория. Origin обновлён на git@github.com:dkoshenkov/paas-common.git
  для fetch и push. Commit и push не выполнялись.
- Go-модулей в paas-ctl и paas-daemon нет; создавать их для переименования не нужно.

## Генерация

Generated-файлы не редактировались вручную. HTTP-пакеты регенерированы Flux
из локального Git-снимка 8f03156 с временным представлением исходных контрактов
в его старом DSL: примитивные поля вместо proto-дескрипторов полей, явные ссылки
на типы и соответствие входного подкаталога http выходному pkg/http.
Все пять результатов побайтово сравнены с прежними артефактами: отличаются
только четыре импорта, содержащие новое имя модуля.

Protobuf регенерирован Flux c4e0b8a647e75d8314286ebd60a19c087e45eb14.
В исходных health.yaml/ready.yaml proto.package согласован с существовавшими
пакетами health/ready, чтобы переименование не меняло RPC-имена.
Go protobuf перегенерирован protoc 3.13.0 и protoc-gen-go 1.36.8,
доступными локально. Временный include google.protobuf.Empty содержит тот же
пустой well-known message и ссылку на стандартный Go-пакет emptypb.
Кроме module path и версий инструментов в заголовках, структура сообщений не менялась.
В grpc.pb.go ссылок на старый module path не было; эти файлы не изменялись.

Исходники соседнего Flux не изменялись; инструменты собирались во временном каталоге.
Это ограниченная регенерация для переименования. Единая закреплённая цепочка make sdk
по текущему DSL остаётся отдельной задачей FLUX-002; полной воспроизводимости её
нынешних defaults этот этап не заявляет.

## Проверки и ограничения

- Строгая проверка OpenSpec после переноса прошла; корень корректно определяется
  как paas-common. git diff --check прошёл.
- go test ./pkg/http/client ./pkg/http/types прошёл (тестовых функций нет;
  подтверждена компиляция этих двух пакетов).
- Полные go build ./... и go test ./pkg/http/... были запущены, но заблокированы
  отсутствующими закреплёнными модулями: среди них grpc v1.83.2,
  protobuf v1.36.12, x/net v0.58.0, x/sys v0.47.0, x/text v0.41.0
  и go-jose/v4 v4.1.4. Существующий module cache доступен только для чтения,
  а DNS к proxy.golang.org/github.com в shell недоступен.
- Зависимости в go.mod не понижались ради прохождения проверки.
- Задача полной Go-проверки остаётся открытой; после появления зависимостей
  выполнить go build ./... и go test ./... из корня paas-common.
