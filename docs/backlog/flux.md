# Backlog Flux для PaaS

- Источник потребностей: `openspec/changes/define-k3s-paas-foundation`.
- Это задачи для отдельного согласования в Flux; исходники Flux здесь не изменяются.

## FLUX-001 — Path-параметры PaaS API

- Статус: проверка необходима до изменения SDK.
- Контекст: PaaS API содержит `/apps/{name}`; `docs/GENERATOR_STATUS.md` Flux
  относит path-параметры к отложенным возможностям.
- Работа: проверить один generated client/server маршрут; при подтверждённом
  пробеле оформить отдельный change Flux без ручного транспорта в PaaS.
- Приёмка: клиент подставляет и кодирует значение, сервер извлекает его,
  OpenAPI согласован с фактическим поведением; результат собирается.

## FLUX-002 — Воспроизводимая генерация PaaS SDK

- Статус: интеграционная проверка после согласования новых контрактов.
- Контекст: Makefile SDK сейчас генерирует только `docs/api/common`;
  SDK содержит HTTP и gRPC, локальный Flux использует packages-go `v0.3.0`.
- Работа: закрепить версию генератора, проверить необходимые targets на реальном
  контракте PaaS и согласованную версию runtime.
- Приёмка: нужные артефакты генерируются, собираются и не меняются при повторной
  генерации; неподдерживаемый target диагностируется явно.
